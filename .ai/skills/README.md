# Project AI Skills

This directory contains reusable skills for AI coding agents working on this project.

## Laravel

| Skill | Description |
|---|---|
| `laravel-10-to-13-upgrade` | Migrate Laravel 10 application to Laravel 13 using fresh foundation approach |
| `application-modernization` | Modernize Laravel 13 architecture, improve maintainability, adopt conventions |
| `thin-controller-refactoring` | Refactor fat controllers into thin controllers with Actions/Services/Form Requests |
| `legacy-code-refactoring` | Improve legacy Laravel, PHP, Vue, and TypeScript code without changing behavior |

## Vue / TypeScript

| Skill | Description |
|---|---|
| `vue-typescript-modernization` | Convert Vue JS to TS, Options API to Composition API, type Inertia props |

## Auditing

| Skill | Description |
|---|---|
| `modernization-audit` | Analyze application and produce prioritized modernization plan |

## Usage

Before performing a substantial task, determine whether one of these skills applies and read it before making changes.
